Your own PaaS, on a box you own.

Mangrove is a small, self-hosted platform. Point it at a Git repo, a Dockerfile, a compose file or an image, and it builds it, runs it, health-checks it and serves it over HTTPS, with blue/green deploys and automatic rollback.

On a Debian or Ubuntu server, clone it git clone https://github.com/evanxdsouza/mangrove.git
Then run the installer cd mangrove && sudo ./setup.sh
It installs Docker and Caddy if they're missing, builds one Go binary, and claims the instance with a single-use setup token so you become its owner. 2 GB of RAM is enough. Re-running it is safe.

Domains

Point a domain at a deployment and Caddy gets and renews its certificate. Behind a home router with no static IP, the built-in DDNS updater keeps the record pointed at you.

shop.example.comCertificate issued
home.example.netDDNS

Access control

Put a deployment behind a password or a Mangrove sign-in, and leave chosen paths open.

Leave open/api/webhooks

Self-healing

Restarts a service after three failed health checks in a row, and retries a failed deploy twice, a minute and then five minutes later.

Idle sleep

Quiet apps stop after a while and wake on the next visit, behind a short "waking up" page, so a small box holds more of them.

Backups and storage

One command captures the database and its encryption key together. On a home server, a plugged-in drive can be shared over SMB through a separate helper, so the control plane never needs mount rights.

$ mangrovectl backup --out mangrove.tar.gz
