Your own PaaS, on a box you own.

Mangrove is a small, self-hosted platform. Point it at a Git repo, a Dockerfile, a compose file or an image, and it builds it, runs it, health-checks it and serves it over HTTPS, with blue/green deploys and automatic rollback.

On a Debian or Ubuntu server, clone it git clone https://github.com/evanxdsouza/mangrove.git
Then run the installer cd mangrove && sudo ./setup.sh
It installs Docker and Caddy if they're missing, builds one Go binary, and creates your owner account. 2 GB of RAM is enough. Re-running it is safe.
Paste this into Claude Code, or any coding agent running on the server Install Mangrove on this server by following https://mangrove-site-evanxdsouz-efde27.apps.automiq.me/install.md. Ask me before anything that uses sudo, and never ask for my admin password.
The agent checks the machine, runs the installer and confirms it's healthy. You set the owner password yourself, in your own terminal, so it never passes through the agent. Read the instructions it follows.
